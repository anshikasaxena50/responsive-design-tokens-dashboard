# Responsive Design Tokens Dashboard

A responsive dashboard built using modern CSS architecture with design tokens, CSS Grid, Flexbox, and mobile-first responsive design.

## Features

- CSS custom properties (design tokens)
- Reusable color, typography, spacing, radius, and shadow variables
- Mobile-first responsive architecture
- CSS Grid for dashboard layouts
- Flexbox for navigation and component alignment
- Responsive breakpoints at 320px, 768px, 1024px, and 1440px
- Light and dark theme support
- Glassmorphism effects with backdrop blur
- Hover transitions and soft shadows
- Responsive project and activity sections
- Accessibility-friendly focus states
- Reduced-motion support
- No horizontal scrolling on small screens

## Technologies

- HTML5
- CSS3
- CSS Custom Properties
- CSS Grid
- Flexbox
- Responsive Web Design

## Responsive Breakpoints

| Breakpoint | Layout |
|---|---|
| 320px+ | Mobile single-column layout |
| 768px+ | Tablet two-column dashboard |
| 1024px+ | Desktop three-column dashboard |
| 1440px+ | Large desktop optimized layout |
